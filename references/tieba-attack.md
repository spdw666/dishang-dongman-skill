# 贴吧式攻击：把话说到对方无法接

这份文件解决一个问题：稿子看着像那么回事，但读完不疼。

不疼的技术原因有七条，先认下来：

1. 每一句都在讲对作品的观察。观察可以被反驳，反驳一成立，攻击就散了。
2. 帽子是心理描述（"需要哄""还信账能算平"）。心理描述是猜测，猜测不构成羞辱。
3. 句子等长、每句抖一个机灵。这是脱口秀的节奏，不是训斥的节奏。
4. 结尾自嘲（"怕给高了说我收钱"）。自嘲把火力卸了。
5. 没有称呼降格。不踩到人身上，骂的是空气。
6. 没有封口。留了接口，对方一句"你懂什么"就能接上。
7. 没有权威背书。判决缺合法性，听起来只是"你不喜欢"。

## 攻击力的来源：取消发言资格

贴吧式攻击的狠，不在用词脏。在于它**不回应内容，直接判定说话的人没资格说话**。被攻击者想反驳，找不到落点——因为对方压根没跟你讨论作品，他在讨论你是不是人。

三个动作按顺序叠加，一篇里的杀伤力就够了：

**降格称呼 → 定性判词 → 封口**

- 降格称呼：把"观众""玩家""粉丝"换成不给体面的说法，或直接换成"它/这货/这帮"。
- 定性判词：一句短、狠、不需要论证的话，钉死人的属性（不是行为，是属性）。
- 封口：一句堵住后续的话，让反驳本身变成新的罪证。

例：`看钢炼的这帮人，本质上就是欠账还不上还想要张收据。行了，别解释，解释就是更想要。`

## 称呼降格表

按从轻到重排。同一篇里不要一路重到底，要有一次突然加码。

| 档位 | 说法 | 用法 |
|---|---|---|
| 轻 | 这位、这货、这帮人、这类人、这号人 | 冷处理，表示"不值得点名" |
| 中 | 孝子、精神股东、赛博孝子、舔狗、龟男、引流狗、跟风的 | 把关系定性为"服务于作品" |
| 重 | 动物、畜生、器官化称呼、用"它"指人 | 取消人格，只在与原作既有调门一致时用 |
| 数量形态 | 一群、一窝、一茬、批发出来的 | 把人变成批次，取消个体差异 |
| 自指 | 鼠人、底层、没出息的 | 说话人先自贬到最底，再俯视对方 |

"哈基米们"是原稿的固定称呼，属于轻档，可用可不用，不设词额。它不能替代更难听的称呼。

## 判词短句

这一类单独成句最有劲。三个字比一段分析狠，因为它不给论证留接口。

- 就这？
- 属于是
- 鉴定为
- 也配
- 差不多得了
- 你谁啊
- 说了你也不懂
- 这话你也敢接
- 谁问你了
- 行了，下一个

`典 / 急 / 孝 / 乐 / 崩 / 麻 / 蚌 / 赢` 属于单字判词，作用是**把一个复杂立场压缩成一个字，取消对方的发言权**。它们是标点，不是内容：一篇里挂两到三处，每处必须挂在具体的人或话上；连用超过五处就退化成烂梗，读起来像刚学会上网。

## 封口句式

攻击完之后不许解释，不许补一句"当然也有好的地方"。封口句的作用是让对方的反驳自动变成新罪证：

- 行了 / 行了行了 / 打住
- 别解释，解释就是更想要
- 你说是，那就是，我不狡辩
- 是是是，你说的都对
- 说了你也不懂 / 懂了也白懂
- 急什么 / 别急 / 慢慢急
- 这话你留着跟自己说

## 假客气反差

先用软语气降低防备，再用一句话猛击。软的那半句要短，硬的那半句要更短。

- `您这话说得可真好呢。可惜脑子是个好东西。`
- `说得挺有道理的呀。可惜没一句对。`
- `理解，都理解。理解完还是那句话：你也配。`

这种反差只能在一篇里用一次。用两次就显出表演。

## 祝福式诅咒

不直接骂，改成祝愿。中文里这是最省力的一种狠，因为字面文明，指向明确。

- 希望人有事
- 祝您早日
- 给您上坟咯
- 愿你以后遇见的都是你这种
- 被钉在历史耻辱柱上（原稿用法）

## 权威背书：伪造引用

这是「地上动漫」比贴吧更狠的一招，必须学会。给判决披一件合法性的外衣，攻击就从"我不喜欢"升级成"自古如此"。

三种做法：

1. **伪造名人语录**。句式"某某说：……"。原稿就把"唯女子与小人为难养也"改成"唯长发男与小人难养也"，还给叔本华、尼采、亚里士多德各派了一句。口气要笃定，不加"我记得""好像"。
2. **套官方话语**。央妈、广电总局、依法、依规、严查、通报、专项治理。把一个小事塞进公文框架，荒谬感自己就出来了。
3. **误引古诗文并挂错作者**。原稿把"商女不知亡国恨"挂给李白（实为杜牧）。这种错不是败笔，是角色的一部分——但一篇里只准错一处，错多了像不学无术而不是装学。

伪造引用只用于虚构对象、作品剧情、泛指人群。真实在世个人的话、真实机构的公告不编。

## 与「地上动漫」原稿的接口

原稿本来就有、只是上一版 skill 没强调够的：

- 称呼降格："具有生育能力的动物""母人""雄性""长发男""婴幼童和大龄巨婴"
- 判词短句："就这""肥水不流外人田""你画不过我""强者就是要利用弱者"
- 封口："言尽于此""该被声讨的人是你们才对""如有冥顽不化者可视程度依法增加改造时间"
- 权威背书：伪造孔子/叔本华/尼采/亚里士多德、央妈、广电总局、依法
- 祝福式诅咒："钉在历史耻辱柱上""被百姓唾弃"
- 数量形态：百分之七十、百分之八十、九十四吨

贴吧侧新增的主要是：单字判词、封口句式的密度、假客气反差、自称鼠人的底层视角。

## 什么不算

- 只把词换脏，句子结构没变。脏词的攻击力低于判词。
- 一排作品名骂过去，没有一个被展开。这是点名册，不是攻击。
- 全篇堆"典急孝乐"，读起来像刚学会上网。
- 骂完补一句"当然这只是我的看法"。这一句把前面全废了。
- 拿真实姓名、真实病史、真实私生活当材料。这不是狠，是换了个战场。
- 通篇都是"纸片人代领优越感""身份认同焦虑"这类概念标签。概念标签是评论员的语言，不是训人的语言。
