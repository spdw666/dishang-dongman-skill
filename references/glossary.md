# 词汇、梗与转写辨误

这是辅助表，不是每篇要装进正文的词袋。作者习惯、公共网络梗、转写杂音和分析者解释分别处理。“语料用法”只说明这批材料怎么用，不承担词源考据。

## 可选声音标记

| 表达 | 作用 | 迁移提醒 |
|---|---|---|
| 哈基米们 | 系列口播观众称呼 | 不是所有形态的开场；动态、续写常不需要 |
| 姐妹们、集帅们 | 临时改变受众站位 | 顺着本篇角色切换 |
| 央妈、咱妈 | 对央视拟亲属称呼，借权威 | 相关议题才用 |
| 匪夷所思、骇人听闻、令人感慨 | 抢先给情绪判断 | 选适合的或不用 |
| 反观隔壁、孰高孰低 | 把比较当裁决 | 应有具体而偏斜的共同尺度 |
| 基本项，不是加分项 | 取消真实优点的功劳 | 学改标准，不复刻原句 |
| 综上所述、满分十分 | 模仿严肃总结 | 评分可顺着论证，也可加码 |
| 神中神、伟大无需多言 | 高强度抬举 | 配具体过誉理由 |
| 我、你们、我们 | 划分论战阵营 | 指向清楚，不随意切换说话人 |

## 词义与素材分类

- 谷子：相关圈层的周边商品。具体购买、收藏行为比空提黑话有效。
- 爆金币：调侃花钱或被索取，依上下文辨认，不等同所有付费。
- 云玩家：对实际体验不足者的质疑；不据此新增某人未玩过的事实。
- 答辩：贬评谐音，不是每篇都需粗口。
- 开盒：身份信息被挖掘或公开的现象；分析话语，不转成行动步骤。
- 电子厂、编制、学历、家长训话：角色可借的尺度，选能接题的，不次次收束到它们。
- 公文腔：如“不辱使命”“初心使命”。效果在小事与重话的比例失衡，不在词串长度。

原版针对性别、国籍等身份的贬称不再当“必须准确”的识别码。用具体行为、话术和歪曲的评判标准承载锋芒，别靠替换群体名称仿写。

兴趣群体可以直接挨骂，喜欢本身就可以被角色判成没见识、没分辨能力。不要先为粉丝寻找一个有据可查的过错才允许刻薄。也别把“门卫、售后、复读机”写成每篇必用称呼；真正主动作是换事件性质、翻转褒贬与倒置责任。
“没品味”“没见过世面”“自我感动”“装懂”属于嘲弄判断；“所有粉丝实际都是什么学历或患什么病”则是不同的事实断言，不用后者给前者加码。

## 帽子与对比的语用

- “附庸风雅”“装懂”“拿资历摆谱”“没见过世面还充内行”：取消受众自封的品味或资格，不只说作品不好。
- “售后复读机”“工龄当品味”“把兴趣当户籍”：按本篇行为制造的贬损类比，不是身份事实，也不是固定口癖。
- “反观隔壁”“比某作还……”：确实换轴、拉踩或反噬受众才算恶意对比，不是连接词出现就完成手法。
- “大清余孽”“反清复明”：原文用作品背景给粉丝定性的帽子。学习其位置和构造，不机械贴到每个新对象。
- 可以把炫耀的东西讥讽成没出息，不给粉丝虚构实际学历、工作、收入或犯罪材料。

## 开场的“高了／低了”

“X高了，Y低了”常是“X的评价给高了，Y的评价给低了”，不是直接排列X高于Y。[54]随后把巨人吹成超越外星文明，[62]随后认定看咒术回战的更高贵，都说明“低了”可以用来极端抬举。对照正文，不只凭两个字判断褒贬。“不如X”才直接把未点名或已点名的另一方压到X下面。

## 易错项

1. ASR 断行不是断句。“范马勇 / 次郎”“病 / 入膏肓”要恢复，错断不是刻意结巴。
2. “of no / of not”：仅凭文字不足以确认音源、说话者、拼写；可能涉及音效、口播、识别。未回听前不列为作者固定口癖。
3. 日语空耳：先辨是不是配乐或剪辑片段。需准确词形就回原视频、官方歌曲或歌词，别凭ASR新增口癖。
4. “遥领先”“复返天罡”等残缺写法：不凭转写认定作者故意说错。新稿通常用清楚可读的惯用形态。
5. “倒反天罡”本身是通行表达，不标成“颠倒天罡”的作者错字。
6. 专名正常化：CLANNAD、矢吹丈、范马勇次郎、芙莉莲、薇尔莉特、JOJO 等对作品核准。
7. 截图分层：作者正文、作者星级、平台总分、他人评论分别读取。
8. 日期分层：截图的二〇二四年十二月不是整批视频年代，文件名时间不直接当首发日期。新稿也不把词库冻结到二〇二四年。

## 原稿的伪证与新稿的推导

分析原稿分别标记真片段、恶意改名、假动机、伪数据与夸张自述；新稿的真假混接主要落在剧情解释和定性，不为现实对象伪造调查来源。
荒诞放在评判标准和推导上。采用假权威或假机构时，让情境本身明确虚构，同稿数据自洽。
不以“所有词条已联网核实”代替逐项证据。本轮以本地文字、截图校准声音，没有回听八十一条原视频，也没有逐项完成所有梗的词源考据。

## 真假与反写词典

- 指鹿为马：同一动作被恶意换名，如帮助→收买、努力→表演；不是多骂一句“垃圾”。
- 黑白颠倒：褒贬、善恶或责任被反判；角色把反判当常识继续讲。
- 半真半假：读者认得剧情支点，但解释与动机已被换掉；不是有一半句子必须有真实统计。
- 无逻辑：结论不由材料合理推出，却摆出首先、其次、众所周知的证明腔；不等于随机词语拼接。
- 人身攻击：让喜欢/相信某作成为观众没品位、不知好歹的罪证；不要求对方先在现实里炫耀或争吵。
