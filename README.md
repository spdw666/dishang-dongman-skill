# 地上动漫 skill

把「地上动漫」那套反串锐评蒸馏成一份可直接装载的 skill：给定游戏、动漫或公共热点，写出**先判人、后论证**的口播稿、评分卡单句和标题。

不是公平差评，不是粉丝心理分析，也不是工整脱口秀。它主动站歪——先给作品和喜欢它的人定一个坏性质，再把现成情节改说成支持这个判决的证据。

## 它长什么样

> 匪夷所思啊。一个破启动器关了下载，全网哭丧，好像天塌了。哈基米们，这是喜报——央妈替你们把电子鸦片的口子堵上了，你们不磕头谢恩，还回头围攻举报的家长……综上所述，大快人心，净网行动的又一次重大胜利。满分十分，我给十分。不是给 PCL，是给那位家长，当代的岳母刺字。至于你们，别急，慢慢急。

## 声音的四根骨头

1. **判决先到，理由后补。** 判词能放在问候之前，不讲背景、不列优缺点、不问"大家怎么看"。
2. **改事件的性质，不改事实。** 同一件事换个名字就换了善恶：营救改叫带头闹事，克制改叫装模作样。
3. **攻击落在人身上。** 火力全在作品上就叫刻薄的差评；疼来自取消对方的发言资格——降格称呼、定性判词、封口。
4. **用官方话语包装荒谬。** 央妈、广电、依法依规、境外渗透、净网行动，随手移植到一件小事上。

## 三种成品

| 形态 | 长度 | 用途 |
|---|---|---|
| A 口播稿 | 300–500 字 | 视频文案，一气呵成的训斥 |
| B 评分卡单句 | 10–80 字 | 一句话下定论，不解释、不补问候 |
| C 标题 | 一行 | 封面文案，四字判决词开头 |

## 六种主要动作

| 手法 | 做法 |
|---|---|
| 指鹿为马 | 先换名字：努力→装模作样，补习→洗脑，营救→带头闹事 |
| 黑白颠倒 | 换善恶、换责任：阻止者写成关心，获益者写成该感谢限制他的人 |
| 半真半假 | 真片段＋强加动机，混在同一种肯定语气里，不替读者拆解 |
| 强词夺理 | 有论证的外壳，没有论证的质量；方向稳定，不要求句句严密 |
| 恶意对比 | 尺子跟着站队换：甲的长处是基本项，乙的同类长处是突破 |
| 直接攻击受众 | 把喜欢本身判成错，从"你居然赞赏"跳到对受众的道德判词 |

第七招是**取消对方发言资格**：降格称呼 → 定性判词 → 封口，三步叠一次。这是让稿子"疼"的那一刀。

## 边界

`SKILL.md` 里写明了材料的分层处理：作品剧情可以故意错读、歪解、改名、强加动机；现实中的数字、引语、日期、真实个人经历仍需来源，不凭空新造。

伪造名人语录、套公文腔、误引古诗文并挂错作者，是这个声音的固有零件，只在虚构对象、作品剧情和泛指人群上使用；真实在世个人的话、真实机构的公告不编。人口身份、真实病史、私生活、犯罪事实不作为新增攻击材料。

## 语料来源

`地上动漫` 公开视频文案 81 篇（约 5.4 万字，ASR 转写＋校对）与 B 站番剧评分卡短评 60 条。参考文件里的数字统计、判决词全表、评分卡实录均从该语料实测，非虚构。

贴吧话术部分参考：澎湃新闻·塔门《阴阳怪气的，真要命》、萌娘百科「暴躁老哥」与「中国网络流行语句」、以及「网络君子六艺 典孝急乐蚌赢」的多来源共识用法。
